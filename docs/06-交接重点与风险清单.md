# atomemo-plugin-sdk-ex - 交接重点与风险清单

## 1. 高风险点
- 参数定义与 codec 逻辑耦合高，微小变更可能破坏旧插件。
- Runtime 与 Hub 通信错误在本地难复现。

## 2. 排查入口
- 参数问题：`ParameterDefinition.*` + `ParameterCodec.*`
- 连接问题：`SocketRuntime.HubClient`
- 执行问题：`CallbackRunner` + 具体工具 callback

## 3. 接手建议
1. 对每种 ParameterDefinition 建立回归用例。
2. 升级前跑插件兼容集成测试。
