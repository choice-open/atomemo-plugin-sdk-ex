# atomemo-plugin-sdk-ex - 模块设计

## 1. 核心模块
- 定义层：`PluginDefinition`、`ToolDefinition`、`CredentialDefinition`、`ModelDefinition`。
- 参数系统：`ParameterDefinition.*` + `ParameterCodec.*` + `ParameterHydrator`。
- 运行时层：`SocketRuntime`、`SocketRuntime.HubClient`、`CallbackRunner`、`HubCaller`。
- 上下文层：`Context.Files`、`Context.LLM`。

## 2. 运行结构
`AtomemoPluginSdk.Application` 在非 test 环境主要维持轻量监督树。
在 test 环境会附加 `Task.Supervisor` 以支持并发测试任务。

## 3. 设计特征
- 使用 Ecto changeset 做“结构化配置校验”。
- 通过 codec 协议把运行时输入映射为强类型参数。
