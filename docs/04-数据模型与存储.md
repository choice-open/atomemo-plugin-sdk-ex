# atomemo-plugin-sdk-ex - 数据模型与存储

## 1. 数据形态
- 主要是内存态配置模型，不依赖本地数据库。
- 关键模型以 `Ecto.Schema` 表达：Plugin/Tool/Credential/Resource* 等。

## 2. 关键结构
- `AtomemoPluginSdk.ParameterDefinition.*`
- `AtomemoPluginSdk.ParameterError.Entry`
- `AtomemoPluginSdk.FileRef` / `ResourceLocator` / `ResourceMapper`

## 3. 一致性关注
- SDK 版本升级可能改变参数语义，需与插件仓库协同升级。
- Hub 协议变更应有向后兼容策略。
