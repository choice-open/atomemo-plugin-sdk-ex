# atomemo-plugin-sdk-ex - 关键流程

## 流程 1：插件定义校验
1. 插件提供定义 map。
2. `PluginDefinition.new/1` 构建并校验 changeset。
3. 若通过，进入 runtime 注册；否则输出结构化错误。

失败路径：
- tool 名称/字段不合法：返回 traverse_errors 结果。
- 参数 default 与类型不匹配：codec 校验失败。

## 流程 2：参数编解码
1. Runtime 接收原始参数（JSON/map）。
2. `ParameterHydrator` + `ParameterCodec` 逐字段转换。
3. 生成可调用插件函数的强类型参数对象。

失败路径：
- 嵌套对象/联合类型不匹配：返回错误路径与原因。

## 流程 3：Hub 交互执行
1. `SocketRuntime.HubClient` 建立连接并订阅 topic。
2. Hub 下发 tool 调用请求。
3. SDK 校验参数并执行 callback。
4. 返回结果或错误到 Hub。
